HOW TO USE YOUR OS

🔐

1. Check in every day

At the start of a new calendar day, the OS locks. Enter your Master Passcode to start that day's cycle and keep your streak alive.

🎯

2. Complete today's tasks

Finish every task shown for today. Five exercise tasks rotate daily, while the core routine stays available every day.

⚡

3. Earn XP & level up

Completing tasks earns XP. Submit the day when you're finished. A flawless day gives a bonus; failing the daily evaluation can cost XP.

🏆

4. Track your milestones

Open Trophies to see achievements. Keep your streak going to unlock bigger milestones and the hidden Day 200 surprise.

💾

5. Protect your progress

Your progress is saved automatically in this browser using local storage. For extra safety, use Profile → Data & Backup → Export Backup and keep the JSON file somewhere safe. You can import that file later if browser/site data is cleared.
